নূর আমল | Muslim Reminder — ওয়েব অ্যাপ

ফাইলসমূহ:
- index.html: অ্যাপের মূল ফাইল
- manifest.webmanifest: হোম স্ক্রিনে ইনস্টলযোগ্য PWA পরিচিতি
- sw.js: মূল অ্যাপ ফাইল অফলাইনে ক্যাশ করার ব্যবস্থা

মোবাইল থেকে চালানোর নিয়ম:
১) ZIP ফাইলটি আনজিপ করুন।
২) এই তিনটি ফাইল একসঙ্গে একটি GitHub repository-তে আপলোড করুন অথবা আপনার HTTPS ওয়েব হোস্টিংয়ে আপলোড করুন।
৩) GitHub Pages চালু করলে একটি https:// লিংক পাবেন।
৪) Android Chrome-এ সেই HTTPS লিংক খুলে ⋮ > Add to Home screen / Install app চাপুন।

গুরুত্বপূর্ণ সীমাবদ্ধতা ও সততা:
- এটি একটি কার্যকর PWA starter/web app; Android APK নয়।
- কুরআনের আরবি ও বাংলা অনুবাদ AlQuran Cloud API থেকে অনলাইনে আসে; প্রথমবার প্রতিটি খোলা সূরা ব্রাউজারে ক্যাশ হতে পারে। পুরো কুরআন/অডিও অফলাইনে ডাউনলোড করার ব্যবস্থা এখনো নেই।
- নির্বাচিত হাদিসগুলো নমুনা, পূর্ণ বুখারি/মুসলিম/অন্যান্য হাদিস ডেটাবেস নয়। প্রকাশের আগে নির্ভরযোগ্য সংস্করণ ও অনুবাদ দিয়ে যাচাই/সম্প্রসারণ করতে হবে।
- নামাজের সময় AlAdhan API থেকে শহরভিত্তিক আসে। গণনা পদ্ধতি ও স্থানীয় মসজিদের সময় মিলিয়ে নিন। শহর নির্বাচন করা যায়; GPS-ভিত্তিক স্বয়ংক্রিয় স্থান নির্ধারণ এখনো নেই।
- কিবলা দিক GPS অবস্থান ও গাণিতিক হিসাব থেকে আসে; ফোনের কম্পাস সেন্সর-ভিত্তিক ঘূর্ণায়মান নির্দেশক এখনো নেই।
- বাংলা ভয়েস পরীক্ষা ব্রাউজারের Speech Synthesis ব্যবহার করে। ব্রাউজার বন্ধ থাকলে নির্দিষ্ট বিরতিতে কথা বলা বা আজান বাজানোর নির্ভরযোগ্য ব্যবস্থা PWA-তে নেই।
- প্রতিদিনের রিপোর্ট ও সেটিংস ওই ডিভাইস/ব্রাউজারের localStorage-এ থাকে; অ্যাকাউন্ট/ক্লাউড সিঙ্ক নেই।
- অনলাইন API-নির্ভর ফিচার প্রথমবার ইন্টারনেট চাইবে। PWA shell একবার হোস্ট ও লোড হলে মূল ইন্টারফেস অফলাইনে খুলতে পারবে।

কুরআন/হাদিসের বিষয়বস্তু যাচাই না করে ধর্মীয় অ্যাপ হিসেবে ব্যাপকভাবে প্রকাশ করবেন না।
